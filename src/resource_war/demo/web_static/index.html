    How it works

    Two sides send three units each across an 8 by 8 map to collect crystals. Score is crystals collected plus tiles owned after 40 turns. Movement is the same simple rule for everyone, so the only thing that differs between players is how they decide.

    Standoffs

    When both sides reach the same crystal, each secretly picks Attack, Defend or Expand. For a crystal worth V, with attack cost c = 2 and defend cost d = 1, Blue's payoff is:

    Orange attacksOrange defendsOrange expands
    Blue attacksbattle: V − c if Blue wins−cV − c
    Blue defendsV − d−d−d
    Blue expands0VV/2

    Below V = 2c, expanding is always better than attacking, so both sides build and share. Above it, the game turns into rock-paper-scissors and the best play is to mix.

    Battles

    If both attack, two units each fight on a front and rear rank for up to 10 moves. Each side looks ahead with minimax; alpha-beta pruning finds the same move while checking fewer positions. More HP left in the fight wins the crystal.
