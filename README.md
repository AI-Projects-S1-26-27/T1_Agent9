# Resource War: Strategic Agents in a Territory-Conquest Game

Course project for **CS F407 Artificial Intelligence**, BITS Pilani, Hyderabad Campus.
Team Agent9. Topic: Agents and Game Theory. Track: Demo.

Two players send units across an 8×8 map to collect resources. The project studies two kinds of
decision that arise in the same game:

- **Simultaneous decisions.** When units of both players reach the same resource cell, each player
  secretly chooses Attack, Defend or Expand. These encounters are analysed as normal-form games:
  dominance, pure and mixed Nash equilibria, and Pareto optimality.
- **Sequential decisions.** When both players attack, a short alternating-move battle decides the
  cell. Each side plays it with depth-limited minimax, and alpha-beta pruning is compared against
  plain minimax.

The two layers are coupled: the payoff for a mutual attack is computed from the measured probability
of winning the battle at each player's search depth. This makes it possible to measure how an
advantage in lookahead changes the equilibrium of the simultaneous game.

## Features

- Exact game-theoretic analysis in rational arithmetic:
  - support enumeration;
  - vertex enumeration for degenerate games;
  - an independent best-response verifier;
  - cross-checks against [nashpy](https://github.com/drvinceknight/Nashpy).
- Battle Mode with minimax and alpha-beta search, instrumented with node counts and timings, and
  benchmarked on a fixed set of positions.
- Five agent types, from a simple heuristic to an equilibrium player and an opponent-modelling
  learner.
- Reproducible experiments:
  - seeded games, side-swapped pairings, and confidence intervals;
  - predictions registered before the experiments were run;
  - every result regenerated by a single command.
- An interactive browser demo in which every decision is explained step by step.

## Getting started

Python 3.11 or newer is required.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate      macOS / Linux: source .venv/bin/activate
pip install -r requirements.txt
pip install -e .
pytest
```

## Interactive demo

```bash
python -m resource_war.demo.web
```

This opens the demo at http://127.0.0.1:8765. It runs locally and does not need an internet
connection.

| Mode | What it offers |
|---|---|
| Watch | Two AI agents play a full game. Every move, encounter and battle move can be stepped through forwards and backwards. Each step explains the decision: both players' reasoning, the payoff matrix, the Nash equilibrium and, for battles, the moves the search considered and how much work alpha-beta saved. |
| Play | Play against any of the agents. You choose every encounter and battle move, with optional advice. Earlier decisions can be undone or changed, because the game is deterministic for a given seed. |
| Explore | Adjust the resource value, the costs and the battle-win probabilities, and see the equilibrium analysis update immediately. |

A command-line interface provides the same functionality without a browser:

```bash
python -m resource_war.demo.cli play --agents equilibrium fixed_mixed --depths 3 3 --seed 7
python -m resource_war.demo.cli analyze --value 6
python -m resource_war.demo.cli battle --depths 1 5 --seed 3
```

## Reproducing the results

```bash
python -m resource_war.reproduce
```

This command runs every experiment from the configuration in `config/` and fixed seeds, then
rebuilds:

- the result files in `experiments/results/`;
- the tables and figures in `report/`;
- the project report, `report/report.md`.

All numbers in the report are generated from these files.

## Repository structure

```
config/                  game, payoff, battle, agent and experiment parameters
src/resource_war/
  engine/                board, movement rules and the seeded turn loop
  encounter/             payoff matrices, dominance, pure Nash equilibria, Pareto analysis
  equilibrium/           mixed equilibria, verification and nashpy cross-checks
  battle/                Battle Mode rules, evaluation, minimax and alpha-beta
  agents/                the five agent types
  tournament/            tournament runner, statistics, experiments, figures
  demo/                  interactive web demo and command-line interface
experiments/             fixed benchmark positions and experiment results
report/                  project report, tables and figures
tests/                   automated tests
```
